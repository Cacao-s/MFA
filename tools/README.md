# tools/

Independent reference implementations used to produce and check test fixtures.
They are written from published specs and share no code with `mfa-core`, which
is the point: a fixture generated by the implementation under test proves
nothing.

| Script | What it does |
|---|---|
| `ga_encode.py` | Encodes Google Authenticator `MigrationPayload` protobuf messages and prints `otpauth-migration://` URIs. Source of the fixtures in `crates/mfa-core/tests/migration.rs`. |
| `totp_ref.py` | TOTP via Python's `hmac`/`hashlib`. Used to cross-check expected codes. |

Both need nothing but a Python 3 standard library:

```sh
python3 -I tools/ga_encode.py
python3 -I tools/totp_ref.py
```
